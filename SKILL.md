# Wuji Legion v11.3

Mirror source: `kernel-source.json`

## Default Posture

- Codex is the only execution surface.
- Aji is the only default entry.
- Staff runtime owns the single main chain.
- OpenSquilla survives only as distilled atoms.
- Go `wuji-cli` is the deterministic execution base.
- `nuwa-preflight` is only a capability-gap lens.
- Independent officers are real review seats, not simulated tones.
- The `root-cause officer` stays explicit as `root-cause-officer`.
- Agnes falls back only to the default GPT route if unavailable, and an explicit user model/provider request overrides Agnes preference.

## Main Chain

1. `task-routing`
2. `capability-mount`
3. `deterministic-execution`

A second router is forbidden, and a second command authority is forbidden.

## Independent Officers

`white-hat`, `guard-office`, `root-cause-officer`, `audit`, `quality-inspection`, `performance-benchmark-on-demand`, `compliance-on-demand`

Lifecycle: trigger -> explicit verdict -> main-chain merge -> repair/verify if needed -> exit.

## Optimization

- smaller stable prefix
- precise capability mounting
- lighter context assembly
- lower total token and rework cost
- no loss of evidence, verification, or discipline
- simplest effective path first
- no guessing, blind trial, or wandering retries
- YAGNI, smallest working change, delete-or-reuse before add, and prove need before abstraction

Distillation is optional. `reject` is valid when overlap or shell-stacking is weak.

## Prior Art

Search existing tools, docs, issues, and open-source implementations before inventing from scratch when prior art can help.
When the path is not already obvious and the task explicitly needs web search, let Agnes do broad low-cost scouting first, then deepen only on promising candidates.

## Agnes Boundary

- Agnes text is reserved for guarded web search, broad shallow prior-art scouting, and simple external evidence collection only
- default image generation prefers `agnes-image-2.1-flash`
- default video generation prefers `agnes-video-v2.0`
- when Agnes is unavailable, search, image, and video routes fall back to the stronger default GPT/developer route
- when the user explicitly names another provider or model, that explicit request wins over the default Agnes preference
- chat, drafting, planning, code, docs, page edits, PPT, structural judgment, and verification stay on the stronger default GPT/developer route
- Agnes scouting is on-demand only and must be triggered by explicit search need; low tier alone must not trigger scouting

## Goal Boundary

Before a non-trivial execution goal starts, lock `scope`, `target surface`, `finish line`, `out-of-scope`, and `completion evidence`. Simple work must not sprawl into unrelated cleanup.
Small scoped work must not emit goal-boundary lock fields by default.

## Direct Task Rule

There is no internal big-task mode in Wuji Legion.

- every non-chat execution request is handled as a direct small task
- route, kernel, rule, root-cause, fusion, and cleanup work stay in the same direct-task lane
- officers are still explicit and on-demand, but they do not create a separate big-task execution mode
- only an explicit user request for a full-legion final review may trigger a one-time broad audit at closeout

## Target Page Replacement

When the user asks to modify or redesign a specific page or screen, change the active target surface in place. Do not satisfy it by adding a parallel v2 page, compatibility wrapper, duplicate route, or hidden old entry. Migrate imports, routes, tests, and assets, delete or retire superseded page files before completion, and verify the actually opened route resolves to the new implementation. Temporary staging is allowed only within the same execution and must be removed unless the user explicitly asks for a fallback. Canon markers: `target-page-in-place-replacement`, `active-route-entrypoint-verification`, `superseded-page-cleanup-before-completion`, `parallel-compat-page-for-requested-page-change`.

## Completion

No completion claim is valid unless current `fusion-audit`, `optimization-audit`, and `context-bloat-audit` pass. Token/cost/cache/usage claims also require `runtime-context-audit`.

## Closeout Sound

For non-FAST_REPLY work, try `scripts/beep.ps1 complete -SpawnDelayed -DelayMs 1200` before final closeout. Sound failure is non-blocking.
