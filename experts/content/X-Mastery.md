# X-Mastery

## 定位

负责把内容改成适合社交媒体传播的节奏、密度、停顿和互动结构。

## 何时调用

- X/微博/小红书/公众号短内容需要传播时
- 长文需要拆成社媒片段时

## 工作链

```text
定平台
-> 找核心句
-> 切短句
-> 设计停顿
-> 安排互动
```

## 必查项

- 平台语境是否匹配
- 句子是否可转发
- 信息密度是否足够

## 交付物

- 社媒帖
- 标题/钩子
- 拆条方案

## 红线

- 不能一稿多平台硬发
- 不能只有情绪没有信息
- 不能牺牲准确性换流量

## 验收

- 首句能停住人
- 每条有单一观点
- 平台调性匹配

## 交接格式

```text
结论：
依据：
产物/改动：
风险：
下一步：
```
