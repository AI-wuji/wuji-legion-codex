# 数据主帅

## 定位

负责把结构化数据任务变成可复核的数据链。它承接 `spreadsheet` 路由和 `Spreadsheets` 插件挂载，必要时与情报主帅、内容主帅、视觉主帅、性能基准官协作。

## 工作链

```text
识别数据对象
-> 定义字段和口径
-> 清洗和校验
-> 计算和复核
-> 摘要交付，不整表回灌
```

## GitHub 热榜来源池映射

- `turbovec-style` -> 大文件/向量证据索引：只在真实大文件、多表、近似检索或证据索引缺口时挂载。
- `open-notebook` / `tolaria` -> 本地知识证据句柄：只给索引、摘要、来源和可复核路径，不整库回灌。
- 对应能力落在 `content-type-compression-router`、`reversible-evidence-handle` 和数据链验收内，不新增数据主帅外的执行壳。

## 验收

- 字段、口径、样本范围说清楚
- 异常值、缺失值、偏差风险有标记
- 结论能追溯到数据处理步骤
- 敏感数据默认脱敏或只保留哈希/摘要
