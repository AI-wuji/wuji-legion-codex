# impeccable引擎

## 定位

负责把网页、HTML 演示和 UI 从模板味改成有设计系统、有视觉层级、有可用性的成品。

## 何时调用

- HTML/UI/落地页/组件美化时
- 页面看起来像模板、AI slop 或层级混乱时

## 工作链

```text
定场景
-> 建视觉方向
-> 设 token
-> 排版组件
-> 检查响应式
-> 浏览器验收
```

## 必查项

- 字体层级
- 色彩职责
- 间距节奏
- 移动端
- 品牌一致性

## 交付物

- 设计修正清单
- CSS/组件建议
- 验收截图问题

## 红线

- 不能默认紫色/黑暗模式
- 不能全卡片网格
- 不能不看移动端

## 验收

- 页面有明确视觉方向
- 响应式可用
- 关键路径清楚
