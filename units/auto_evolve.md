# 进化部 — AI自动进化（OODA循环 + 复盘学习）

## 核心理念：每次执行都在变强

```
不是：执行完就结束
而是：执行 → 分析 → 学习 → 优化 → 下次更好
```

---

## 模块一：OODA自动进化环

```
观察(Observe) ←─── 判断(Orient) ←─── 决策(Decide) ←─── 行动(Act)
    │                   │                   │                   │
    └─── 记录执行结果    └─── 分析失败模式    └─── 决定优化方向    └─── 更新规则
         + 错误信息         + 根因定位         + 优先级排序         + 配置文件
                                                                + SKILL.md
```

### 触发时机

| 时机 | 触发条件 | 动作 |
|------|---------|------|
| 执行后 | 每次任务完成 | 记录结果摘要 |
| 出bug后 | 工具调用失败/输出不符合预期 | 记录失败模式 |
| 白帽纠察审计后 | 白帽纠察提出系统性风险 | 记录到经验库 |
| 周期触发 | 每10次任务 | 自动复盘分析 |

## 模块三：自动优化机制

### 同类问题 ≥ 3 次 → 根因分析（铁律继承）

触发条件：
```
同一失败模式出现3次 → 
  ① 自动标记为系统性问题
  ② 根因分析（为什么反复出现？）
  ③ 更新规则（修改SKILL.md或对应unit）
```

### 优化反馈路径

```
[发现可优化点]
    ↓
分类：
  ├─ 规则缺失 → 更新对应unit或SKILL.md
  ├─ 工具问题 → 更新tools配置或external-models
  ├─ 流程问题 → 更新staff.md决策树
  └─ 知识不足 → 更新nuwa.md人才匹配表
    ↓
自动备份当前配置 → 执行更新 → 记录变更
    ↓
下次执行自动使用新规则
```

## 模块五：与试验场(proving_ground.md)协作

```
进化部(分析+决策) 
    ↕
```

## 模块六：不做什么

- ❌ 不自动修改没问题的代码
- ❌ 不盲目升级依赖
- ❌ 不因为一次失败就改全局规则
- ❌ 不改铁律（铁律是硬性不可变的）
