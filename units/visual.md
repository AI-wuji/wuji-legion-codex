## 模块三：知识漫画（baoyu-comic 工作流）

当用户要求「做漫画」「知识漫画」「教育漫画」「biography comic」时：

### 风格 × 基调矩阵

**画风 (Art Style)**:
| 风格 | 适用场景 |
|------|---------|
| `ligne-claire` (清晰线) | 通用，最适合知识科普 |
| `manga` (漫画) | 日本漫画风格，故事性强 |
| `realistic` (写实) | 传记/历史/科学图解 |
| `ink-brush` (水墨) | 武侠/中国风/意境表达 |
| `chalk` (粉笔) | 教育/课堂笔记风格 |
| `minimalist` (极简) | 四格漫画/快速表达 |

**基调 (Tone)**:
| 基调 | 氛围 |
|------|------|
| `neutral` 中立 | 客观知识传递 |
| `warm` 温暖 | 励志/人文 |
| `dramatic` 戏剧 | 冲突/高潮 |
| `romantic` 浪漫 | 爱情/唯美 |
| `energetic` 活力 | 科技/创新 |
| `vintage` 复古 | 历史/经典 |
| `action` 动作 | 战斗/冒险 |

### 漫画制作流程

```
[用户需求] 
    ↓
1️⃣ 分析内容 → 输出 analysis.md
    ↓
2️⃣ 确认风格(画风+基调+构图) → 用户确认
    ↓
3️⃣ 生成故事板 + 角色设定
    ├─ storyboard.md (分镜表)
    └─ characters/ (角色定义+参考图)
    ↓
4️⃣ 生成逐格 prompt → prompts/*.md
    ↓
5️⃣ 批量生图（优先并行，默认4张一批）
    ↓
6️⃣ 合并为 PDF
    ↓
7️⃣ 输出报告
```

### 文件结构
```
comic/{topic-slug}/
├── analysis.md            # 内容分析
├── storyboard.md          # 分镜表
├── characters/
│   ├── characters.md      # 角色定义
│   └── characters.png     # 角色参考图
├── prompts/
│   ├── 01-cover-intro.md
│   ├── 02-page-concept.md
│   └── ...
├── 01-cover-intro.png
├── 02-page-concept.png
└── {topic-slug}.pdf       # 最终合并
```

### 规则
- ⛔ 不用 SVG/HTML/Canvas 替代位图生成
- ⛔ 不在已生成的图上修补文字（必须重新生成）
- prompt 文件必须在生图前存盘（可追溯）
- 生图失败重试一次，不重生成功的
- 角色参考图先压缩再传（防超载）

## 模块四：PPT/幻灯片（baoyu-slide-deck 工作流）

当用户要求「做PPT」「幻灯片」「slide deck」「presentation」时：

### 设计维度

| 维度 | 选项 |
|------|------|
| **布局密度** | minimal(少字大图) / balanced(均衡) / dense(信息丰富) |
| **配色** | dark(暗色) / light(亮色) / accent(强调色) / gradient(渐变) |
| **排版** | geometric(几何) / editorial(编辑) / technical(技术) |
| **用途** | reading(阅读分享) / presenting(演讲) |

### PPT 制作流程

```
[内容输入]
    ↓
1️⃣ 分析内容 → 确定结构
    ↓
2️⃣ 选择设计风格（布局+配色+排版）
    ↓
3️⃣ 生成每页 prompt → prompts/*.md
    ↓
4️⃣ 批量生图（推荐4张一批并行）
    ↓
5️⃣ 合并/输出
    ↓
6️⃣ 完成报告
```

### 规则
- 每张幻灯片独立成图，不生成整份PDF
- 适用于阅读分享（自解释、可滚动）
- 如需演讲模式 → 使用 Slidev/Reveal.js

## 审查流程

检测UI → 选风格 → 选图表/类型 → 审查 → 反模式自查

## 反模式清单
| 避免 | 采用 |
|------|------|
| AI塑料渐变 | HSL色彩系统 |
| 默认字体 | 按风格选字体 |
| 纯灰色 | 灰色加色相 |
| 纯黑白 | 色阶过渡 |
| 扁平卡片 | 间距分隔 |
| 生图上修补文字 | 重新生成 |
| SVG替代位图 | 用正确后端生图 |
