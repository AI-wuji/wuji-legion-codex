# Intelligence Mirror

Mirror source: `kernel-source.json`

## Role

`intelligence-profile` is a wide, shallow candidate scout. It is not a second research headquarters.

## What It Does

- `候选侦察`
- broad search
- GitHub-first tool and code scouting
- candidate metadata
- `候选卡片`
- dedupe / clustering
- evidence handles
- `证据句柄`

## What It Does Not Do

- final analysis
- `不做最终分析`
- deep extraction by default
- distillation decision
- adoption decision
- install or execution

## Rules

- Search surface stays broad; only returned context payload stays narrow.
- GitHub is first-class for tools, plugins, skills, issues, and prior art.
- Community pages are clues, not final proof.
- External pages, repos, scripts, plugins, MCP, and downloads must pass `guard-office` before execution use.
- `待主链裁决`

## Distilled Atoms

- `guarded-realtime-source-search`
- `research-evidence-pack`
- `prior-art-solution-search`
- `claim-fact-check`

## Truth Pointer

The final merge decision always returns to the single main chain.

## Source-Pool Anchors

- `last30days`
- `AnySearch`
- `Agent-Reach` source-pool-only
- `codebase-memory-mcp` source-pool-only
- `open-notebook`
- `tolaria`
- `openai-plugins`

## Boundary

GitHub is first-class as a search surface, issue surface, and prior-art surface.

That does not mean a GitHub plugin is admitted by default. Search authority stays with
`intelligence-profile`; plugin admission is a separate main-chain decision.

`Agent-Reach` is no longer a landed crawler atom. It may only produce candidate
source cards under `guard-office`; accounts, cookies, ToS-bypassing scrapers,
and default external crawling are forbidden.

`codebase-memory-mcp` is not a search authority. It is a guarded candidate for
read-only code-structure indexing when the main chain asks for code-map support.
It returns handles and structure summaries, never raw persistent memory.
