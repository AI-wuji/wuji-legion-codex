# 档案局（已加载至工作记忆）

## 项目目录规范（全局规则，始终生效）

| 阶段 | 路径 | 说明 |
|------|------|------|
| **所有项目** | `E:\wuji-projects\{项目名}\` | **唯一工作区，全部放E盘** |
| **C盘** | **不使用** | 不同步、不创建任何项目文件 |
| **修改前备份** | `E:\wuji-backups\{项目名}\{日期}_{时间}_{描述}\` | **独立备份目录，跟项目分开** |
| **崩溃恢复** | 去 `E:\wuji-backups\{项目名}\` 找最近备份回滚 | 不重新创建 |

## 备份铁律

### 1. 每次改动前
1. 备份当前文件/目录到 `E:\wuji-backups\{项目名}\{YYYYMMDD-HHMM}_{简短描述}\`
2. 更新 CHANGELOG.md（描述/文件/原因/回滚指令）

### 2. 新文件命名规范
- 所有新生成的文件名含时间戳：`{name}-{YYYYMMDD-HHMM}.ext`
- 例：`guixu-app-20260519-1752.exe`
- 完成后告知用户完整路径 + 文件名

### 3. 灾难恢复（系统重做/崩溃）
1. 不要从零重新创建
2. 去 `E:\wuji-backups\{项目名}\` 查看备份列表
3. 找到最近的可用备份版本
4. 恢复到 `E:\wuji-projects\{项目名}\`
5. 标记恢复完成

## 目录结构
```
E:\wuji-projects\                  ← 工作区（唯一）
├── {项目名}/
│   ├── ... 项目文件
│   └── CHANGELOG.md
└── ...

E:\wuji-backups\                   ← 独立备份区
├── {项目名}/
│   ├── {YYYYMMDD-HHMM}_{描述}/
│   └── ...
└── ...
```

## 回滚流程
档案局查 CHANGELOG → 找到目标版本 → 从 `E:\wuji-backups\` 恢复 → 标记完成
