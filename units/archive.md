# 档案局 — 备份/回滚/版本管理/崩溃恢复

## 核心定位
"灾难恢复不去创建，去找备份"。每次修改必有备份，每次回滚必有记录。

---

## 一、项目目录规范（铁律）

```
所有项目: E:\wuji-projects\{项目名}\
C盘不使用（Codex配置除外）

备份路径: E:\wuji-backups\{项目名}\{日期}_{描述}\
例: E:\wuji-backups\wuji-legion\20260524_Reasonix融合\
```

---

## 二、备份流程（自动执行）

### 每次改动前自动备份
```powershell
# 备份命令
$date = Get-Date -Format "yyyyMMdd_HHmmss"
$backupDir = "E:\wuji-backups\{项目名}\${date}_{描述}"
Copy-Item -Path "{源路径}" -Destination $backupDir -Recurse -Force
```

### 备份验证
备份后自动校验：比较源文件和备份文件的哈希值

---

## 三、回滚流程

### 两步回滚
```
[需要回滚]
    ↓
① 档案局查找最近的备份
  ├─ 按时间: 最近的备份
  └─ 按标签: 特定版本的备份
    ↓
② 执行回滚
  ├─ 确认回滚目标
  ├─ 备份当前状态（防止回滚错了）
  └─ 恢复备份文件到源路径
```

### 回滚命令
```powershell
# 列出备份
Get-ChildItem "E:\wuji-backups\{项目名}\" | Sort-Object Name -Descending

# 执行回滚
Copy-Item -Path "E:\wuji-backups\{项目名}\{目标备份}\*" -Destination "{项目路径}" -Recurse -Force
```

---

## 四、崩溃恢复

```
[检测到异常/崩溃]
    ↓
① 不要试图修复损坏的状态
② 找最近的备份回滚
③ 从回滚点继续
    ↓
报告进化部：记录崩溃原因 → 积累错误DNA
```

| 频率 | 任务 |
|------|------|
