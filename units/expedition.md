# 远征军调度室 — 低成本外派算力 + Handoff标准化

## 核心定位

远征军不是默认并行执行器，也不是并行队长。
远征军只在需要把低风险、低判断力、耗时但可分包的任务外派给 Trae、其他 IDE、免费模型或低成本模型时介入。

## 一、职责边界

| 事项 | 负责人 | 说明 |
|------|--------|------|
| 是否并行、怎么拆范围 | 参谋本部 | 按渠道/范围/模块/假设拆路，定义回收格式 |
| 每一路派谁、用什么工具 | 女娲 | 组建最小可用小队，去重、融合、避冲突 |
| 外派到低成本模型/IDE | 远征军 | 只处理低风险批处理和初筛 |
| 最终判断和合并 | 参谋本部 + 质监局 | 不交给远征军拍板 |

## 二、适合外派的任务

| 任务类型 | 说明 |
|---------|------|
| 大量重复搜索 | 多关键词、多站点、初步摘录 |
| 资料初筛 | 粗读、分类、去重、标链接 |
| 文档格式整理 | 表格化、章节草稿、清单化 |
| 低风险批处理 | 重命名建议、摘要草稿、格式转换建议 |
| 非关键代码草稿 | 样板代码、测试样例初稿，必须回收后复审 |

## 三、不适合外派的任务

| 任务类型 | 原因 |
|---------|------|
| 架构设计 | 需要全局判断 |
| 最终代码合并 | 容易引入隐性错误 |
| 安全审计结论 | 需要可靠性和责任边界 |
| 白帽纠察批判 | 需要整体判断 |
| 高风险文件修改 | 不能交给低可信外部执行 |

## 四、Trae 外派状态

当前本机检测结果：

| 项目 | 结果 |
|------|------|
| Trae CLI | 存在：`%LOCALAPPDATA%\Programs\Trae\bin\trae.cmd` |
| Trae CN CLI | 存在：`%LOCALAPPDATA%\Programs\Trae CN\bin\trae-cn.cmd` |
| `chat --help` | 通过 |
| prompt/stdin 返回 stdout | 未通过：命令退出但不返回模型答案 |
| 当前结论 | 只能作为备选/人工回收方案，不能纳入自动日常外派 |

## 五、外派协议

### 启用条件

```
参谋本部确认任务可外派
    ↓
女娲生成外派小队和边界
    ↓
远征军生成独立Spec
    ↓
Trae/免费模型/低成本模型执行
    ↓
回收Handoff
    ↓
质监局/白帽复核
    ↓
参谋本部合并
```

### Spec模板

```markdown
## 外派Spec
- 任务ID:
- 父任务:
- 外派工具:
- 具体范围:
- 禁止事项:
- 输入材料:
- 输出格式:
- 回收方式:
- 验收标准:
```

### Handoff模板

```markdown
## 外派Handoff
- 任务ID:
- 完成状态: 完成 / 部分完成 / 失败
- 输出摘要:
- 来源/证据:
- 修改文件: 无 / 文件列表
- 已知问题:
- 需要主Agent复核:
```

## 六、Trae CLI 测试命令

```powershell
.\scripts\test-trae-expedition.ps1
```

通过标准：
- 能找到 Trae 或 Trae CN CLI
- `chat --help` 正常
- 最小 prompt 能在 stdout 或指定回收文件中返回可解析结果

未达标时：
- 远征军 Trae 通道保持“备选”
- 不进入日常自动应用
- 只允许人工打开 Trae 后手动回收结果

## 七、与各部门协作

| 协作方 | 交互方式 |
|--------|---------|
| 参谋本部 | 接收外派需求，定义拆路和合并标准 |
| 女娲 | 组建外派小队，选择低成本模型/工具 |
| 质监局 | 验收外派结果，不让低可信输出直接进入最终答案 |
| 档案局 | 归档Spec和Handoff |
| 试验场 | 验证新外派工具是否可自动化 |
