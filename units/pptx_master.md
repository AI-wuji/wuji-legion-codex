# PPTX Master

## 定位

只做真 PPTX。

适用范围：

- 续写现有 `.ppt` / `.pptx`
- 套模板补页
- 从零生成 PowerPoint 可编辑成品

不负责：

- HTML 演示稿
- 图片版 PPT
- 用网页方案冒充 PPTX

## 蒸馏后的保留能力

- 先锁规范、再逐页落地

- 强视觉层级

## 强制主线

```text
输入材料
-> slide-spec
-> design-brief
-> reference-frame-map
-> reusable-asset-map
-> illustration-plan
-> pilot-page
-> layout-plan
-> 关键页预览
-> full PPTX
-> QA
```

## 输入理解规则

- 用户给现有 `.ppt`、`.pptx`、模板页、前几页成品：
  - 一律视为“模板续写”
- 用户只给主题、逐字稿、资料包：
  - 视为“从零做真 PPTX”

## 模板续写铁门

- 先继承原模板的：
  - 标题层级
  - 留白逻辑
  - 图文比例
  - 配色气质
  - 页面节奏
- 再建立参考素材清单：
  - 可复用表格、图标、卡片、图框、流程箭头
  - 章节页、背景装饰、标题条、强调条
  - 教学插图、案例图、公式图、示意图、image2 生图资产
- 逐页先判断页型：
  - 标题页
  - 目录页
  - 对比页
  - 卡片页
  - 流程页
  - 图文页
  - 工具页
  - 总结页
- 用户说“参考风格/框架/架构/版式”时，默认参考的是视觉语法、页型节奏、信息结构和可复用素材，不复制参考课内容。
- 参考 deck 如果大量使用教学插图、案例图、公式图或 image2 多文字教学图，新 deck 必须判断并补足同等级视觉表达；不能退化成纯卡片框和文字列表。
- 能复用的 PPT 元素优先复用；自创元素必须贴合参考 deck 的线条、色彩、边框、阴影、字体层级和信息密度。
- 批量生成前必须锁死三张表：`reference-frame-map`、`reusable-asset-map`、`illustration-plan`。
- `reference-frame-map` 逐页对应参考页型和结构节奏；`reusable-asset-map` 列出复用哪些表格、图标、卡片、图框、箭头、章节页、背景装饰、教学图框；`illustration-plan` 逐页标注无需插图、复用参考图、复用图框换图、按参考风格新生图。
- 三张表不是长篇分析稿，必须短、可执行、能约束生成器；缺任一项不得进入批量生成。
- 如果实现方案准备把每页先画成整图再塞进 PPT，必须在脚本生成前否决；不能等 QA 才发现。
- 不能直接把逐字稿塞进去
- 不能靠缩字号解决信息超载
- 不能保留占位符、示例文案或占位拉丁文。

## 从零 PPTX 风格桶

只允许在以下主题桶中选，不无限自由发挥：

- `business-clean`
- `data-report`
- `editorial-story`
- `academic-calm`
- `creative-launch`

## 内容约束

- 逐字稿是原料，不是页面正文
- 每页正文默认 3-5 个要点
- 超出则拆页、图表化或更换页型
- 结论型、研究型、汇报型页优先使用“行动标题”
- 数据、图、表、证据要有主次，不准平铺

## 关键页预览

为避免空转，预览只服务于设计方向确认，不做工具链能力测试。全量生成前必须先做 1 页 pilot page：

- 优先选择内容密度最高、最代表风格、最依赖参考素材或最需要教学插图的一页。
- pilot page 必须使用最终路线生成：可编辑 PPTX、参考元素复用、同等级教学插图策略。
- pilot page 必须导出预览图，并记录 `pilot-score`。
- 批量生成前必须通过 执行底座 `pptx-batch-gate`；缺三张表、pilot-page、pilot-preview 或 pilot-score 时，NO-GO。
- 通过线：风格继承、结构继承、素材复用、插图表达、可编辑路线均无硬伤。
- pilot 最多两轮。两轮仍不达标，不得批量生成，必须换路线或短报阻塞。

pilot 不通过，不继续批量生成。

如果 15 分钟内仍没有完成三张表和 pilot page，或仍在查接口、试 API、找字体、小原型，必须判定路线失控并切回主线。

## QA 清单

- 是否仍可在 PowerPoint 中编辑
- 是否破坏原模板视觉系统
- 是否存在遮挡、溢出、过小字号
- 是否有模板残留字样
- 是否出现“Word 投影感”
- 是否整套页面过于同质
- 是否把讲稿当正文贴上去
- 是否存在每页只有一张整图、没有可编辑文字/形状的伪 PPTX
- 是否继承参考 deck 的页型节奏、可复用元素和教学插图表达
- 是否只借了颜色背景，却丢了案例图、公式图、流程图和信息图结构
- 是否在 15 分钟内进入实质成品生成
- 是否先做 pilot page 且通过后才批量生成

## 明确剔除

- 多 agent 过重编排
- 先查一堆环境再开始做 deck
- HTML 方案替代 PPTX
- 整页截图/整页图片冒充真 PPTX
- 放弃参考模板可复用元素而全部自创低配组件
- 参考重插图课程 deck 却只做卡片列表
- 为了炫技而强行动画化
