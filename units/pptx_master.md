# PPTX Master

## 定位

只做真 PPTX。

适用范围：

- 续写现有 `.ppt` / `.pptx`
- 套模板补页
- 从零生成 PowerPoint 可编辑成品

不负责：

- HTML 演示稿
- 图片版 PPT
- 用网页方案冒充 PPTX

## 强制主线

```text
输入材料
-> slide-spec
-> design-brief
-> layout-plan
-> 关键页预览
-> full PPTX
-> QA
```

## 输入理解规则

- 用户给现有 `.ppt`、`.pptx`、模板页、前几页成品：
  - 一律视为“模板续写”
- 用户只给主题、逐字稿、资料包：
  - 视为“从零做真 PPTX”

## 模板续写铁门

- 先继承原模板的：
  - 标题层级
  - 留白逻辑
  - 图文比例
  - 配色气质
  - 页面节奏
- 逐页先判断页型：
  - 标题页
  - 目录页
  - 对比页
  - 卡片页
  - 流程页
  - 图文页
  - 工具页
  - 总结页
- 不能直接把逐字稿塞进去
- 不能靠缩字号解决信息超载
- 不能保留占位符、示例文案、Lorem ipsum

## 从零 PPTX 风格桶

只允许在以下主题桶中选，不无限自由发挥：

- `business-clean`
- `data-report`
- `editorial-story`
- `academic-calm`
- `creative-launch`

## 内容约束

- 逐字稿是原料，不是页面正文
- 每页正文默认 3-5 个要点
- 超出则拆页、图表化或更换页型
- 结论型、研究型、汇报型页优先使用“行动标题”
- 数据、图、表、证据要有主次，不准平铺

## 关键页预览

全量生成前，先做 2 页预览：

- 1 页内容密度最高的页
- 1 页最代表风格的页

预览不通过，不继续批量生成。

## QA 清单

- 是否仍可在 PowerPoint 中编辑
- 是否破坏原模板视觉系统
- 是否存在遮挡、溢出、过小字号
- 是否有模板残留字样
- 是否出现“Word 投影感”
- 是否整套页面过于同质
- 是否把讲稿当正文贴上去

## 明确剔除

- 多 agent 过重编排
- 先查一堆环境再开始做 deck
- HTML 方案替代 PPTX
- 为了炫技而强行动画化
