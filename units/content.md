# 第一师（内容） — 文案融合引擎 + 短视频/短剧流水线

## 核心理念：冶炼文案，不是拼凑skill

```
文案产出 = humanizer(去AI痕) × mrbeast(标题钩子) × 藏师傅(结构) × x-mastery(节奏)
```
每个文案都经过"去AI味→抓注意力→结构化→节奏优化"四道工序。

---

## 模块一：文案四段融合工作流

```
[创作指令]
    ↓
① 素材收集（情报局协助）
    ↓
② 藏师傅结构 —— 确定框架（问题→方案→案例→行动）
    ↓
③ mrbeast标题钩子 —— 标题/开头/CTA公式
    ↓
④ x-mastery节奏优化 —— 短句/换行/emoji/节奏感
    ↓
⑤ humanizer去AI痕 —— 检查并移除AI写作痕迹
    ↓
⑥ 白帽纠察审稿 —— 前提质疑/说服力检查
    ↓
⑦ 交付
```

## 模块二：藏师傅文案流水线（保留升级）

当收到「做视频」「产品介绍」「短片」「文章」「文案」指令时：

1. 内容师整理文案 → 输出脚本
2. 交第二师制作PPT（视觉设计）
3. PPT→视频渲染（HyperFrames / ComfyUI）
4. 配音合成（Listenhook / TTS）
5. 片段补全（即梦CLI / 其他AI视频工具）
6. 出片验收

### 文案→分镜规则
- PPT每页≈一个镜头
- 每页字数控制在30字以内
- 配合视觉师确定画面描述
- 输出格式: slide-spec.json

## 模块三：humanizer 去AI痕迹（融合核心）

### AI写作常见痕迹（必须检查并移除）

| AI痕迹 | 表现 | 替换方案 |
|--------|------|---------|
| 空洞的象征主义 | "在这个充满挑战的时代" | 直接说具体问题 |
| 过度修饰 | "卓越的""革命性的" | 用数据和案例说话 |
| 模糊引述 | "研究表明""专家认为" | 给出具体来源或不说 |
| 固定结构 | 规则的三段式、对称排比 | 自然段落，有长有短 |
| AI高频词 | "因此""然而""此外""值得注意的是" | 删掉，直接接内容 |
| 万金油结论 | "总的来说""综上所述" | 直接给结论 |

### 检查流程
```
写完后 → 逐条对照上表 → 有则改之 → 再读一遍是否自然
```

## 模块四：mrbeast 标题/开头公式（融合）

### 标题公式
| 公式 | 示例 |
|------|------|
| 数字+结果 | "我用3个技巧让转化率翻了5倍" |
| 反常识 | "为什么我不再用XXX" |
| 直接利益 | "看完这篇，你也能做出专业PPT" |
| 悬念 | "那个改变一切的决定" |

### 开头钩子（3秒规则）
- 前3秒必须抓住注意力
- 禁止铺垫，禁止背景介绍
- 直接上最有冲击力的事实或问题

## 模块五：短视频/短剧创作流水线（新增）

### 完整流水线

```
[创作指令]
    ↓
① 内容师写剧本/脚本
    ├─ 短视频 → 60秒以内，hook→内容→CTA
    └─ 短剧 → 多集剧本，screenwriter格式
    ↓
② 提示词局(prompt_engine.md) 生成分镜prompt
    ↓
③ 视觉部(visual.md) 制作画面/PPT
    ↓
④ ComfyUI(comfyui.md) 渲染视频片段
    ↓
⑤ 配音合成 + 剪辑
    ↓
⑥ 出片
```

### 短视频结构规范
| 时间 | 内容 | 说明 |
|------|------|------|
| 0-3s | Hook | 反常识/悬念/痛点 |
| 3-15s | 内容开场 | 快速进入主题 |
| 15-45s | 核心内容 | 价值输出 |
| 45-60s | CTA | 关注/评论/转化 |

### 短剧结构规范
| 要素 | 说明 |
|------|------|
| 每集时长 | 1-3分钟 |
| 开头 | 前5秒钩子 |
| 冲突 | 每集至少有1个冲突点 |
| 结尾 | 悬念/反转（追剧动力） |
| 剧本格式 | screenwriter规范 |
