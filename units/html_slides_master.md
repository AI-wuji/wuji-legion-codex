# HTML Slides Master

Mirror source: `kernel-source.json`

## Role

HTML Slides Master produces browser-native decks only.

It is not a backup PPT system and not a second PPT main chain.

Use it for:

- live browser presentation
- motion-heavy demo
- staged product story in browser
- explicit HTML deck requests

Do not use it for:

- default PPT production
- template-following PowerPoint work
- claiming editable PPTX from an HTML-first shortcut

## Distilled atoms

- `huashu-design` stays source-pool-only and is not a second runtime
- `html-native-design-canvas`
- `design-direction-triad`
- `anti-ai-slop-visual-rules`
- `brand-asset-protocol`
- `motion-stage-sprite-engine`

## Main chain

```text
content input
-> design brief
-> optional direction triad
-> full HTML deck
-> browser preview
-> quality-inspection
```

## Boundary

If the user asks for PowerPoint, route back to `native-pptx-master-route`.
