# 专家契约与 MoE 路由

无极军团采用“静默专家、按需唤醒”的 MoE 结构。专家不是常驻模型，也不是第二个用户入口，而是由阿极选择的任务级契约。目录见 `capabilities/experts/manifest.json`。

## 生命周期

```text
自然语言 -> 阿极识别场景 -> 选择 0/1 个主专家（必要时 1 个辅助专家）
          -> 装载固定 Skill/MCP/插件组合 -> 参谋部生成有界任务图
          -> 执行节点 -> 独立验证 -> 反馈账本
```

没有命中、证据不足、预算不足或白帽判断认为不合理时，专家保持缄默，阿极直接澄清、拒绝或走最小通用路径。专家不得自行唤醒其他专家、扩大权限、修改路由规则或宣布完成。

## 契约字段

每个专家必须声明触发词与反例、固定能力组合、允许/禁止工具、输入输出格式、时间/字节/重试预算、白帽拒绝条件和独立验收探针。固定组合是稳定先验；任务契约可以在必要时覆盖可选步骤，但不能绕过安全、证据和预算门禁。

## 进化

专家升级只接受真实失败、复用、来源和验证事件。新流程先作为候选版本运行对照测试；只有独立验证文件、SHA-256、边界复核和内容寻址 promotion receipt 齐全，才允许替换当前版本。失败候选保持可追溯但不自动进入路由。
