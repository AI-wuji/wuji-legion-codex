# Source Execution Status

This is the operational boundary for every retained Skill, MCP candidate, template package, and upstream snapshot. The machine-readable runtime inventory is produced by:

```powershell
.\bin\wuji.exe source-audit
```

`source-audit` covers registered manifest sources. The full legacy decision inventory is `migration/legacy-verdict-ledger.json`; it is regenerated by `scripts/build-legacy-ledger.ps1` and deliberately keeps upstream objects cold unless each object has its own adapter and evidence.

`auto-selectable` means the router can select one scenario source and prepare a verified native-host contract for its exact entrypoint. It does **not** mean the Skill or MCP has run. The host re-reads the entrypoint and verifies its SHA-256/byte count before passing it to a native child. Only a host-native attestation or a real tool result plus task evidence can prove execution. A receipt file proves contract consistency only; route JSON, mounts, source contracts, prompt injection, smoke output, and external `codex exec` cannot.

| Capability | Automatic execution surface | Retained material deliberately kept cold |
| --- | --- | --- |
| Code | Native Aji code route with the behavior-verified Ponytail protocol in its worker contract | Complete Ponytail snapshot; it is provenance and regression material, not a second coding runtime. |
| Code review | Local `wuji-code-review-suite` source, automatically selected for review tasks | Complete Open Code Review source is cold provenance only. |
| Context / knowledge / evolution | Native bounded Go commands | Codebase Memory MCP binary is retained but its isolated index probe failed and it has no registered adapter; GraphRAG and Context Mode remain cold references. None is an automatic MCP route. |
| Data | `wuji-data-suite` | Statistical, RAG, and spreadsheet packages are internal alternatives; only the selected analysis path may be read. |
| Documents | `wuji-document-suite`; `officecli-stateless-adapter` only for explicit Word/Excel HTML render or structure-dump tasks | Word, PDF, and spreadsheet packages remain selected only by requested output format; OfficeCLI never owns the document route or PPT work. |
| Frontend | `wuji-frontend-suite` | Builder, browser-test, and electronic-board packages are implementation atoms, never parallel page workflows. |
| Feishu / Lark | Official `feishu-lark` Skill with authenticated `lark-cli`; links and Feishu tasks automatically select its narrow read-first instruction surface | Third-party Feishu MCP servers are not retained or routed. Existing cloud content is read-only unless the user explicitly names the target and requested change. |
| Image / video / visual | Their matching unified scenario Skills and explicit provider routing | Provider-specific assets stay cold unless the request selects their provider or medium. |
| Search | `wuji-research-suite` | Browser, URL, YouTube, and Electron extractors are chosen only for the matching source type. Firecrawl is deferred: no adapter, credential policy, or behavior comparison exists. |
| Writing | `wuji-writing-suite` | Writing, humanization, translation, and platform adapters are mutually exclusive scenario atoms; publishing remains explicit-authority only. |

Their compatible rules are distilled into the two scenario contracts; they are not competing default deck generators. |
| Security | `wuji-security-suite` | Scanner and CI/CD packages remain scoped internal scanners, not a full-suite default. |

## External candidate verdicts

- **Ponytail:** behavior-verified for local code-route/contract behavior, not end-to-end native-child execution and not as a separately mounted Skill.
- **OpenSpec:** behavior-verified local strict change-capsule gate; automatically required only for high-risk changes.
- **agent-skills and mattpocock/skills:** compatible practices are implemented in local routing and verification contracts. Their upstream packages are not installed or called fused.
- **Superpowers:** retired on 2026-07-23. The upstream package was never installed; its local failure-task fan-out and derived worker prompts, including the fresh-regression instruction, were removed for efficiency. Historical review and migration evidence remain audit-only and are not runtime inputs.
- **DashiAI PPT:** the local `wuji-dashiai-deck-adapter` is behavior-verified and narrowly auto-selectable; complete upstream source/templates are cold because the upstream repository has no reusable license. A native-host attestation and task result are still required before a task can say the adapter was used.
- **Codebase Memory MCP:** the locked `0.9.0` binary is present but not registered as a Codex MCP server; its isolated index probe did not pass. It remains unavailable for routing until a root-cause fix and a comparative index/search behavior probe pass.
- **Firecrawl:** deferred and unavailable. Its service/credential boundary and comparative behavior probe are not present, so it must not appear in an automatic route.
- **Official Lark CLI:** `feishu` is an automatically selectable callable capability through the `feishu-lark` Skill. Installation and the structured authentication-status contract are smoke-tested; authentication still requires explicit user setup, and a real document operation is required before claiming a particular read or edit executed.
- **OfficeCLI:** `officecli-stateless-adapter` is behavior-verified for narrow, read-only `.docx`/`.xlsx` HTML and JSON exports by `scripts/verify-officecli.ps1`. It does not register MCP, modify PATH, install upstream skills, or leave a resident process; a specific user-file operation still needs its real tool result.

The router must never treat cold retained material, a manifest record, a source mount, route declaration, source contract, source injection, or an external CLI result as proof that an MCP tool executed. A tool execution claim additionally requires its installed adapter, validated arguments, structured tool result, and result hash. The only currently usable MCP-adjacent integration is the globally installed official Lark CLI through its real Skill/tool surface; it is selected for Feishu links and Lark tasks, while edits still require explicit authorization. Codebase Memory MCP and Firecrawl remain cold/unavailable and cannot be auto-routed.
