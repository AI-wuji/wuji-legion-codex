# Wuji Video Suite

Choose one delivery path internally: direct generation, image-to-video, or composed motion/timeline output. Agnes is the declared default; an explicit user provider wins. A route's provider ID does not prove a working API adapter, free quota, credentials or completed video. Check callability before use; if Agnes is unavailable, ask before switching to a potentially paid GPT provider. Use HyperFrames/Remotion only for requested composition or deterministic rendering. Verify duration, dimensions, nonblank frames, playback and output format.

For editing in 剪映/CapCut or audio/soundscape work in REAPER, route to the local editor lane, not Agnes or a generation fallback. Only mount the selected editing or audio expert's cold workflow. A routing contract never proves that the desktop application was controlled or an export exists.
