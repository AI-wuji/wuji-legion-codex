# Wuji Security Suite

Lock the scan boundary first. Run only relevant checks, deduplicate findings, order by severity and exploitability, and provide file/line evidence plus remediation. Never launch a full scanner suite for a narrow question. Verification and release evidence remain read-only unless the user explicitly authorizes changes.
