# Wuji Frontend Suite

Inspect the active route and implementation first. Modify the real page in place, remove superseded files and routes, and use the project's existing framework. Apply the builder and testing packages as one workflow: implement the smallest complete change, launch the real app, inspect desktop/mobile rendering, interaction, console errors, and screenshots, then fix only observed defects.

Do not create compatibility pages, parallel v2 routes, decorative landing pages, or duplicated component systems unless explicitly requested.
