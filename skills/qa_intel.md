# 📋 质监局 SOP

## 验收标准
每个子任务产出必须通过：
1. ✅ 功能完整性 — 实现了需求描述的每个点
2. ✅ 代码质量 — 简洁、无冗余、命名清晰
3. ✅ 安全基线 — 无注入/XSS/硬编码密钥
4. ✅ 错误DNA预检 — 不引入已知错误模式
5. ✅ 测试验证 — 修改可被验证

## 错误DNA维护
- 每次 bug 修复后 → 自动记录到 ERRORS.md
- 每次代码修改前 → 自动检查 ERRORS.md
- 每次新 bug 修复 → 跑 dedup 检测相似度
- 相似度 ≥70% → 告警
- 第 3 次 → 强制根因分析

# 📡 第五师（情报作战师）SOP

## 搜索模板
```
同时搜索：
├─ 竞品/同类产品
├─ GitHub (关键词 + sort:stars)
├─ 社区/论坛
├─ 技术方案/最佳实践
└─ 安全/许可证审查
```

## 评估标准
每个搜索结果标注：
- 来源 / Star 数
- 核心内容摘要
- 可信度：高/中/低
- 可融合性：高/中/低
- 安全评级：✅ 安全 / ⚠️ 注意

## 情报汇总格式
```
📡 情报报告

1. [竞品] xxx | 核心功能 | 评价
2. [GitHub] xxx (⭐⭐) | 描述 | 可融合性
3. [社区] xxx | 讨论热度 | 结论
4. [技术] xxx | 方案对比 | 推荐
---
🔒 安全审核：通过
```
