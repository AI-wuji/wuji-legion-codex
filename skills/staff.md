# 🎖️ 参谋本部 SOP

## 职责
接收阿极总结 → 制定作战方案 → 调度各师 → 汇总结果

## 工作流
```
接收简报
    ↓
分析需求类型 → 确定涉及师团
    ↓
【情报先行】→ 调第五师全网并行搜索
    │
【安全审核】→ 安全局审查情报
    │
【制定计划】→ 拆解子任务
    │
【并发派发】→ spawn_agent 各师同时执行
    │
【质检验收】→ 质监局审核所有产出
    │
【评估决策】
    ├─ 达标 → 最终汇总
    ├─ 需迭代 → 返回情报步（≤3轮）
    └─ 重复输出 → 立即停止
    │
【阿极汇报】→ 含文件路径+时间+提示音
```

## 调度规则
| 关键词 | 调用 | 说明 |
|--------|------|------|
| ComfyUI/插件/节点/工作流 | 第三师 | 插件合并/开发/反向工程 |
| 软件/EXE/打包/图表/展牌/HTML | 第四师 | 开发+图表+打包+加密 |
| UI/界面/设计/美观/视觉 | 第二师 | 联动 impeccable |
| PPT/演示/内容/文案 | 第一师 | 内容生成 |
| 搜索/调研/竞品/情报 | 第五师 | 全网并行搜索 |
| 安全/加密/反编译/破解/加壳 | 安全局 | 攻防一体 |

## 多轮迭代控制
```
轮次变量 R = 0
开始:
  R += 1
  执行一轮()
  
  if check_output_duplicate(本轮, 上轮) > 85%:
    停止("检测到输出重复")
    break
  
  if R >= 3:
    询问用户("已完成3轮，是否继续？")
    if 用户说不: break
  
  if 目标达成: break
  else: goto 开始
```
